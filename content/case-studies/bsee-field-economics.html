BSEE Field Economics Analysis with NPV/IRR

Method notes for engineering and data workflows.

The challenge

Organise the inputs, calculations and reporting into a repeatable workflow with checks.

Our Approach

1

BSEE Data Collection and Validation

Extracted production history from BSEE public datasets covering analogous Gulf of Mexico deepwater fields. Validated data quality, identified and corrected anomalies, and established production decline curves using regression analysis on comparable fields.

2

Production Profile Development

Built type curves with ramp-up, plateau and decline phases. State the production assumptions and compare them with the source data.

3

Financial Modeling and NPV/IRR Calculation

Implemented a monthly cash-flow model with explicit capital, operating-cost, royalty and discount-rate assumptions. Automated NPV and IRR calculations using numpy financial functions.

4

Sensitivity Analysis and Risk Assessment

Generated tornado diagrams showing NPV sensitivity to key variables. Performed Monte Carlo simulation with 10,000 iterations to quantify P10/P50/P90 outcomes.

Technical Implementation

Data Processing Workflow

The analysis leveraged the worldenergydata Python library for BSEE data access and processing:

  • Data Source: BSEE production API (mv_productionsum and lease-level datasets)
  • Analysis Period: 180 months (15 years) from first oil
  • Production Aggregation: Field-level rollup across development leases
  • Decline Modeling: Exponential decline curves fitted to historical performance

Financial model inputs

State the oil price, royalty, operating cost, development capital, discount rate and production assumptions before calculating cash flows.

Technologies & Tools

Data Source: BSEE public production API and lease databases
Data Processing: Python (pandas, numpy) for data extraction and aggregation
Financial Modeling: Custom cash flow calculator with numpy financial functions
Visualization: Static PNG exports for production curves and NPV sensitivity
Reporting: Automated Excel generation with openpyxl
Version Control: Git for model versioning and audit trail
