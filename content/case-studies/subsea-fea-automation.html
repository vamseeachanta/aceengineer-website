Automated FEA Post-Processing Pipeline for Subsea Equipment Qualification

Method notes for engineering and data workflows.

The challenge

Organise the inputs, calculations and reporting into a repeatable workflow with checks.

Our Approach

1

Workflow Analysis & Requirements Gathering

Define the post-processing workflow, data extraction patterns, code check calculations and reporting requirements. Record the input formats and equipment types before implementing the extraction steps.

2

Solver Output Parsing

A Python parser reads the MYSTRAN .F06 text output (displacements, single-point constraint forces, element stresses and the epsilon error estimate) and, where pyNastran is installed, the .op2 binary. MYSTRAN is a NASTRAN-compatible open-source solver.

3

Code Checks

Code checks exist as separate modules: subsea connector end-cap, combined axial and bending (von Mises) and seal preload checks to API 17R / ISO 13628-1; pipeline burst and collapse to DNV-ST-F101; and ASME Section VIII Division 1 shell and head thickness, with ANSYS APDL generation for stress classification line paths.
