Frequently Asked Questions

How does AceEngineer automate engineering workflows?

We replace manual, repetitive engineering workflows with automated pipelines. The workflow can include model setup, batch execution, results extraction and report compilation. Inputs, checks and engineering review are agreed for the stated scope.

What standards do you support?

Standards referenced by the modules include:

  • Fatigue: DNV-RP-C203, API RP 2A, BS 7608, ABS, Norsok
  • Riser/Pipeline: API RP 2RD, API STD 2RD, DNV-OS-F201
  • Offshore Wind: IEC 61400-3, DNV-ST-0126
  • Pressure Vessels: ASME B31.8, API 579

Regression tests cover the DNV-RP-C203 classes listed in the public fatigue calculators, in air, seawater with cathodic protection and free corrosion.

What software tools do you integrate with?

Our primary integrations are:

  • OrcaFlex: Full Python API integration for batch model generation, simulation, and post-processing
  • AQWA: Hydrodynamic model generation, RAO processing, and operability analysis
  • NASTRAN/ANSYS: FEA post-processing automation and report generation
  • Python/Polars: High-performance data processing for large engineering datasets

What are the typical engagement models?

  • Per-project: a defined deliverable for an agreed scope
  • Annual retainer: ongoing automation runs and support
  • Custom development: Time and materials for bespoke automation pipelines

How is intellectual property handled?

Data is completely abstracted from the computational methods. Client-specific configurations and results remain confidential. Where practical and not constrained by IP, our core engineering libraries are open-source for transparency and validation. Client-specific automation scripts are delivered via private repositories.

What engineering quality practices do you follow?

All code follows production software engineering standards:

  • Test-Driven Development (TDD) with comprehensive unit and integration tests
  • Version-controlled, documented, and peer-reviewed code
  • Recorded inputs and results for engineering review
  • Regression tests for the listed DNV-RP-C203 calculator classes in air, seawater with cathodic protection and free corrosion
