Solver automation

Load cases are prepared from scripted inputs and run in batches without a person at the screen. The results are read back into tables, and the engineer reviews the governing cases.

How an OrcaFlex batch runs

  • One YAML input file names the models, the analysis type and the run settings.
  • Statics and dynamics run without the graphical interface, and each simulation is saved.
  • A failed or incomplete case set stops the batch with a FAIL verdict and a non-zero exit code.
  • A run without a solver licence is reported as skipped, never as a pass.
  • Results are read back from the saved simulations into tables for the governing-case review.
